# ADR 0001. Монорепозиторий для микросервисов

- Статус: Accepted
- Дата: 2026-09-23
- Контекст: проект, 7 микросервисов, единый стек, один разработчик.

## Контекст

Проект состоит из 7 микросервисов и 3 общих библиотек.
Нужно выбрать между монорепо и polyrepo.

## Решение

Используем **монорепозиторий** с Maven multi-module.

- `services/` — микросервисы (каждый — отдельный Maven-модуль).
- `libs/` — общие библиотеки.
- `infra/` — docker, helm.
- `docs/` — документация и ADR.

## Последствия

Плюсы:

- Единый CI на весь проект.
- Общие библиотеки без публикации в Nexus.
- Атомарные изменения: контракт + потребитель в одном PR.
- Проще локальный запуск.

Минусы:

- Один pipeline собирает всё — медленнее при росте.
- Сложнее давать доступ к отдельным сервисам.
- Риск связанности модулей без дисциплины.

## Альтернативы

- Polyrepo — отклонено: избыточно для проекта, усложняет общие библиотеки и CI.
